# catalog-service

Standalone Spring Boot project for Tartheeb.

Purpose: Handles the service catalogue, pricing, plans, entitlements, inventory, and warehouses.

## Technology

- Java 21
- Spring Boot 4.1.1
- Spring Web MVC
- Spring Validation
- Spring Boot Actuator

## Run

```powershell
mvn spring-boot:run
```

The application starts on port `8086`. Epic-01 implements versioned service-to-Technician capability requirements used by assignment eligibility checks.
